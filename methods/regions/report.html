01
预测路线 · 图像进入网络

一张原图怎样变成网络输入？

先统一图像尺寸和数值范围，得到骨干能够接收的三通道张量。这一步还没有提取组织特征。

  1. 统一尺寸：读取灰度图，缩放到 256×256。此时只有一个通道，形状为 1×256×256。
  2. 统一数值：像素除以 255，变成 0～1 的浮点数。模型内部把同一份灰度扩展为三个通道，并分别使用固定均值、标准差归一化。
本步接收任意宽高的单张灰度图
交给下一步3×256×256 的归一化图像张量
补充：三个通道里的图像有什么区别？

扩展时三个通道的灰度完全相同；随后分别计算（灰度−均值）／标准差。均值为 0.485、0.456、0.406，标准差为 0.229、0.224、0.225，因此归一化后的数值不同。这是在适配骨干的输入约定，没有产生三份不同的组织观测。

本方案使用固定的 ImageNet 归一化，入口没有原热图模型的可学习去噪卷积。训练样本还可能采用裁剪视图和增强；图像与人工坐标如何同步，放到第 06 节说明。

预测路线 · 骨干提取特征

四级特征不是凭空出现的，它们来自哪里？

同一张图沿 MobileNetV3-Large 连续向后计算，项目在四个位置保留中间输出。保留一份后，原来的计算仍继续向更深处进行。

这张图只看两件事：主线怎样继续向深处计算；哪四个位置把中间结果交给后面的融合模块。

沿主线看：骨干包含多个卷积模块，部分模块执行下采样，空间网格逐步变小。每个编号模块内部可能包含多层卷积。

沿旁路看：在编号 3、6、12、16 的模块后各保留一份，分别得到 24×64×64、40×32×32、112×16×16、960×8×8。编号从 0 开始。

形状中的 24、40、112、960 是骨干这些位置原本的输出通道数；64、32、16、8 是下采样后的空间尺寸。浅层网格较细，保留较多位置细节；深层经过更多加工、通常覆盖更大的输入范围。融合模块希望把这些层次的线索一起用起来。

03
预测路线 · 由深到浅融合

尺寸不同的四级特征，怎样合成一组？

先把通道都变成 64，再逐级放大深层特征，与同尺寸的浅层特征相加、加工。最后得到 64×64×64 的融合结果。

先看整体，再看局部：上半图跟踪四级合成一组；下半图放大一次“尺寸对齐后相加”。

看四个向下的投影箭头：四组特征各过一个可学习的 1×1 卷积，分别变成 64 通道。宽高保持各自的 64、32、16、8；这一步重新组合通道信息，不是截掉多余通道。

看右端的最深起点：最深层的 64×8×8 先独立过一次 3×3 卷积、GroupNorm 和 SiLU。此时还没有与其他层相加。

顺箭头从右向左：当前结果依次放大到 16×16、32×32、64×64。每次与对应浅层的 64 通道投影相加，再过 3×3 卷积、GroupNorm 和 SiLU。

看下半图的单通道数例：用 2×2 放大到 4×4 演示实际的 16×16 放大到 32×32。放大后的 1 与浅层同位置的 4 相加得到 5；其余位置和所有通道都按相同规则逐元素相加。

相加后，为什么还要卷积？为什么宽高不变？

相加把两个来源在对应位置上的数值汇合，仍是 64 通道；后面的 3×3 卷积再学习如何利用周围 3×3 邻域和所有输入通道，重新组织已经汇合的信息。GroupNorm 调整特征数值分布，SiLU 提供非线性。

这些 3×3 卷积使用步长 1、边缘补 1 格，所以宽高不变；输出通道也设为 64。空间尺寸变大，发生在前面的双线性上采样，不是这次卷积。

对照热图法：40＋960＝1000，与这里有什么不同？

原热图方案取 40×32×32 和 960×8×8 两级：将后者放大到 32×32，沿通道拼成 1000×32×32，再卷积压到 40 通道。

当前区域方案取四级，先各自投影成 64 通道，再逐元素相加。拼接会增加通道数；相加保持通道数。因此这里的两个 64 通道相加后仍为 64，不会变成 128，也不是把四个原始通道数直接相加。

04
预测路线 · 生成区域概率

网络输出的两张区域图，各自代表什么？

第一张表示“位于上边界下方”的概率，第二张表示“位于下边界下方”的概率。这里的上、下边界分别是真皮层下界、脂肪层下界。

4.1 先明确输出含义，再看怎样计算

沿图像从上往下读：上方、两条线之间、两条线下方，分别应怎样填色？

两条线以上：两张图都接近 0。两条线之间：第一张接近 1，第二张接近 0。两条线以下：两张图都接近 1。

因此两张图是包含关系。第二张的“下方区域”包含在第一张里面；同一像素可以在两张图里同时接近 1。

4.2 用预测头把特征变成这两个概率

给 64 通道融合特征附加两张位置图：一张标记从上到下的相对位置，一张标记从左到右的相对位置。这里按通道拼接，增加两个位置通道，于是输入变成 66×64×64。预测头先用 3×3 卷积、GroupNorm、SiLU 加工回 64 通道，再用 1×1 卷积输出两个分数。

这张图看数值怎样变：64 个特征通道怎样变成两个分数；两个分数又怎样保证区域的包含关系。

先得两个分数：最后的 1×1 卷积有两组可学习权重，在每个位置把 64 个特征组合成两个数。分数本身尚不是概率。

再得两个概率：第一个分数经 sigmoid 得到上界下方概率；第二个分数经 sigmoid 后，再乘前一个概率，得到下界下方概率。

R上 = sigmoid(z₁)
R下 = R上 × sigmoid(z₂)z₁、z₂：该位置的两个原始分数；R上、R下：对应的两种“在边界下方”的概率。乘积保证 0 ≤ R下 ≤ R上 ≤ 1。例如 0.8×0.5＝0.4。
本步接收64×64×64 融合特征
交给下一步两张 64×64 区域概率图
本节记住两张图并非两个互斥类别；它们也不要求同一列的概率总和为 1。每格都在回答一个“是否位于这条边界下方”的问题。

05
预测路线 · 从面积读取高度

有了区域图，边界坐标怎样算出来？

计算每列“边界上方占了多少”。区域概率 R 表示下方，所以 1−R 表示上方；沿高度相加，再除以格子数，就得到归一化高度。

先只看一条线、一个列：下面用 8 格代替实际的 64 格，把面积到坐标的计算完整算一遍。

① 取补集：R＝[0, 0, 0.5, 1, 1, 1, 1, 1]，因此 1−R＝[1, 1, 0.5, 0, 0, 0, 0, 0]。

② 算占比：上方共有 2.5 格，占整列 2.5／8＝0.3125。

③ 换成像素：256 高的输入，行坐标范围是 0～255，所以得到 0.3125×255＝79.6875 像素。坐标可以是小数，不需要取整。

u(x) = (1／h) ∑i=0…h−1 [1−R(i,x)]
预测高度 = u(x) × 255i 是区域图的行号，x 是列，h 是区域图高度（实际为 64）；u 是归一化高度。这个求和平均，就是代码所说的“区域积分”。

实际网络先对两张 64×64 图分别沿高度平均，得到两条各有 64 列的坐标序列；再沿横向线性插值到 256 列，最后乘 255。横向插值是在已有坐标之间加密，不是在区域图中寻找峰值。

为什么上下两条线不会颠倒？

第 04 节已经保证 R下≤R上，所以 1−R下≥1−R上。取平均后，下边界高度就不小于上边界高度；后续同样的线性插值和尺度换算仍保留这个顺序。

这种顺序约束不代表每张区域图沿高度一定平滑、单调。不同概率排列可能有相同面积，这也是第 07 节还要监督整个区域图的原因。

06
训练路线 · 制作正确答案

人只标了边界点，区域图的答案从哪里来？

先把人工点插成逐列边界，再按每格位于边界下方的比例，自动生成区域标签。这张标签图由人工线计算，不是网络预测的图。

  1. 从点到线：有效人工点按原图整数列分组，同列高度取均值；在点之间线性插值，得到缩放后 256 列的浮点高度。有效范围以首末标注点为界，范围外即使有填充值，也不参与监督。
  2. 从线到区域图网格：将 256 列高度横向重采样到 64 列，并除以 255，得到归一化高度 u。对每一列，完全在边界上方的格子取 0，下方取 1，被边界穿过的格子，取其中位于边界下方的部分占整格的比例。

沿用上一节的同一个数例：人工答案为 79.6875 像素，即 u＝0.3125；在 8 格示意中恰好落在行号为 2 的格子中间（行号从 0 开始）。

读被穿过的那一格：半格位于边界下方，因此标签为 0.5。上面的格子为 0，下面的格子为 1，得到 [0, 0, 0.5, 1, 1, 1, 1, 1]。

与第 05 节接起来：把这张理想标签当成预测图再做补集积分，就会还原 0.3125。这使标签的构造与坐标的解码相互对应。

Q(i,x) = clip(i + 1 − h·u(x), 0, 1)Q 是人工区域标签；i 从 0 开始，h 实际为 64；clip 把数值截到 0～1。它与源码的“行中心减边界高度、乘 h、再加 0.5”完全等价。边界格保留小数，这就是抗锯齿阶跃软标签。
补充：没有标注的列、非整数坐标和裁剪怎样处理？

假设两个有效点为 (2,40)、(6,60)，查询原图横坐标 3.5 时，插值比例为 (3.5−2)／(6−2)＝0.375，因此高度为 40＋0.375×20＝47.5。这个独立小例说明：查询位置和纵坐标都可以是小数，计算不要求取整。

实际先按 j×原图宽／256 查询每个新列的原图位置，再按 256／当前视图高度缩放纵坐标。同列点合并时横坐标会先四舍五入；后面的插值高度保留浮点。原始点与区间内插值点没有额外的来源权重之分；每条线不足两个有效列会报错。

裁剪视图、水平翻转及纵向几何增强需要同步改变图像、坐标与有效掩码；亮度等外观增强不移动坐标。区域监督还会把逐列掩码扩展到每个高度格，只比较有效列。

07
训练路线 · 比较预测与答案

坐标已经有答案，为什么还要监督区域图？

坐标损失检查“面积算出的高度对不对”；区域损失检查“每个位置的上下判断对不对”。相同的面积，可能来自不同甚至错误的概率排列。

仍然看刚才的 8 格：下面两列的区域总量都是 5.5，解码都得 79.6875 像素，但右边的形状明显不对。

坐标项看不出的错误：错误列把一些上方格子赋了较高概率，又把下方格子赋了较低概率；总量恰好抵消，积分坐标没有变。

区域 BCE 逐格纠正：每格都比较预测概率与标签。单调项再限制方向：从上往下走，概率应趋向增大；例如 0.7 降到 0.2，会产生 0.5 的局部惩罚。

五项监督，各自负责一个明确问题

监督项它具体比较什么系数
坐标预测高度与人工高度，修正边界位置。1
斜率预测与人工线的相邻列高度差，修正局部走势。0.4
层厚两条预测线的间距与真实间距，修正层厚。0.05
区域 BCE每格预测概率 R 与人工标签 Q，修正完整区域形状。1.0
纵向单调惩罚往下走概率反而降低，抑制上下反复。0.5
L监督 = L坐标 + 0.4L斜率 + 0.05L层厚 + L区域 + 0.5L单调前三项采用 Smooth L1。斜率比较的是预测差分与人工差分，不是强迫真实边界变平。系数来自当前配置，其中单调系数写在源码里。
进一步计算：BCE、单调项和加权细节

单格区域误差为 −[Q·ln(R)＋(1−Q)·ln(1−R)]。R 越符合该格标签 Q，误差越小；Q＝0.5 时允许部分覆盖。这里逐格比较“在边界下方／不在下方”的概率，不对整列做 softmax。

纵向相邻两格的局部惩罚为 max(R(i)−R(i＋1),0)，再在有效位置求平均。它是软约束，不能保证每一列在任何时候都严格单调。

坐标 Smooth L1 的 β＝3 像素，两条线的加权平均权重为 1.372、1.387；斜率项 β＝1、厚度项 β＝2。区域概率先限制在 10−5～1−10−5，BCE 使用 FP32 计算。不同项的单位、归一化与误差范围不同，不能只按外部系数大小判断谁更重要。

无效位置不计入损失；斜率要求相邻两列均有效，层厚要求两条线均有效。当前资料没有提供足以证明这些超参数是最优值的调参结果。

本节记住监督同时约束边界坐标、曲线形状和区域内部的概率形状。它们汇总成一个可反向传播的标量。

08
训练路线 · 从误差到参数更新

监督已经定义好，网络怎样一步步学会？

先用人工答案训练教师，再让学生同时学习人工答案和冻结教师的输出。两者使用同样的区域表示和解码方式，骨干不同：教师为 ResNet18，本文学生为 MobileNetV3-Large。

这张图只看学生训练：教师和学生看的是同一份增强图像；教师在哪些列更可信，就相对多学那些列。

教师先冻结：学生训练时，教师只给预测，不更新参数。人工标签仍直接监督学生，不会被教师替代。

按误差分配相对信任：教师坐标误差为 0、8、16 像素时，门控约为 1、0.368、0.135。随后还会按权重总和归一化，主要调整各位置之间的相对影响。

  1. 前向预测：同一批图像进入可训练网络；学生阶段同时运行冻结教师。按前面 01～05 步得到区域图和边界。
  2. 汇总损失：教师只用第 07 节的人工监督；学生在此基础上，再比较自己的坐标、区域概率与教师输出。
  3. 反向更新：每微批 16 张，损失按当前组实际批数归一后反向传播。通常累积 3 批，再裁剪梯度、执行一次 AdamW 更新、清空梯度。骨干、融合模块和预测头一起参与学习。
  4. 验证选模：每轮结束评估两条线的误差，按平衡评分保存最佳模型。达到最少训练轮数后，长期无改进可以早停。
本项目实际使用的蒸馏公式与训练参数
门控 = 有效掩码 × exp(−|教师高度−人工高度|／8)
L学生 = L监督 + 0.55 × min(轮次／10,1) × L蒸馏区域法的 L蒸馏 是门控加权坐标 Smooth L1 ＋ 门控加权区域 Bernoulli KL。这里两个蒸馏子项之间没有额外的 0.5 系数。

基础学习率 0.0007，AdamW 权重衰减 10−4；前 5 个调度索引预热，随后余弦下降。总梯度范数裁剪阈值为 5；最后一组不足 3 批时使用实际批数作为除数。

教师最多 100 轮、学生最多 80 轮；至少训练 40 轮后，距最佳轮达到 20 轮且没有新改进，可早停。选优评分为两条线“当前 MAE／固定参考 MAE”中的较大者，再加 0.05 倍两者平均；参考值约为 1.10525、2.02256，它们不是本次新测出的结果。

训练结束后，怎样在一张新图上使用？

只加载最终学生模型，重走 01～05 的预测路线。新图不需要人工标注，也不需要教师。

模型得到 256 列坐标后，推理程序按原图宽度重新插值，纵坐标乘原图高／256，输出原图每一列的两条边界并写入 JSON。这一步恢复的是坐标尺度，不再训练模型。

学完再对照：它与原热图法的关键差别

环节原热图方案当前区域方案
融合两级特征，通道拼接后卷积。四级特征，统一 64 通道后逐级相加与卷积。
输出含义边界在各个高度处的评分。每格位于某条边界下方的概率。
坐标解码沿高度归一化，再求坐标期望。沿高度平均区域补集，再恢复横向列数。
图形监督以人工边界为中心的高斯软目标。按人工边界切分格子的阶跃软标签。
整条主线：图像经骨干得到四级特征，融合后预测两张嵌套区域图，区域补集积分得到边界；训练再用人工坐标、区域标签和教师输出纠正这些预测。
