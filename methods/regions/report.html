区域法：先判断边界上下，再从面积读出高度。

本节对应 072_区域调优 的 ordinal_regions 配置。它仍预测真皮层下界与脂肪层下界，但不再让网络在边界处形成高斯亮峰，而是预测“这个像素位于该边界下方”的概率。

每条边界对应一张区域图：在边界上方接近 0，下方接近 1。两张图是包含关系，深处的像素可以同时位于两条边界下方。它们不是两个互斥类别，也不是一张“脂肪／背景”分类图。脂肪位于上界下方、下界上方；理想情况下两张区域图相减才得到中间层的区域。

环节原热图方案当前区域方案
特征与融合两尺度拼接后卷积四尺度从深到浅逐级上采样、相加与加工
监督图形边界附近的高斯软目标边界下方的抗锯齿阶跃目标

学习方式真实标注监督教师真实标注监督；学生再增加可信教师蒸馏

因此，这不只是换一个损失名称：输入归一化、取用的骨干层、特征融合、输出含义及坐标解码都改变了。卷积等通用基础可回看热图法的结构说明，下面集中解释当前方法的区别。

固定视图与联合变换，保留同一套坐标约定

数据从固定索引选择原图或裁底视图。人工点先按原图整数列分组，同列纵坐标取均值；新图第 j 列查询原图横坐标 j×原图宽／256，在已知点之间线性插值。首末点外虽有端点填充值，仍标记无效；不足两列有效点会报错。插值高度保留小数，原始点和插值点没有额外权重区分。

图像裁剪后缩放到 256×256，坐标同步乘 256／当前视图高度。训练时图像、坐标与有效掩码共同水平翻转，或做三选一的纵向几何变换；裁掉有效标注时更新掩码，并要求每条线仍保留监督。随后加入配置允许的亮度、对比度、散斑等外观变化。区域法配置的伪亮带概率为 0。

外部图像张量只有一个灰度通道，取值除以 255 后在 0～1。模型内部再把它扩展成三个通道，使用固定均值和标准差归一化，以接入标准骨干；这里没有旧模型的可学习高斯去噪层。标注插值裁剪与坐标换算

四级特征逐步恢复细节，再明确上下关系

以附带学生权重对应的 MobileNetV3-Large、256×256 输入为例，骨干取出四级特征：24×64×64、40×32×32、112×16×16、960×8×8。每一级先用 1×1 卷积投影为 64 通道。最深层投影后先经过一次 3×3 卷积、8 组 GroupNorm 和 SiLU，加工成融合的起点；这一层还没有与其他尺度相加。随后三层依次把当前特征上采样到下一浅层尺寸，与该层投影逐元素相加，再经过同样的 3×3 卷积、GroupNorm 和 SiLU，最终得到 64×64×64 的融合特征。教师换成 ResNet18 后通道数不同，仍经过四级侧向投影接入同样的融合形式。

模型再拼入两张从 0 到 1 的横纵位置图，让预测头直接知道当前像素处于什么相对位置。于是区域头输入为 64＋2＝66 通道，经 3×3 加工成 64 通道，再用 1×1 卷积产生两张原始评分图 z₁、z₂。

R上＝sigmoid(z₁)
R下＝R上 · sigmoid(z₂)
0 ≤ R下 ≤ R上 ≤ 1

这种乘积构造使“下边界下方”始终包含在“上边界下方”中；两张图同一像素可以都接近 1。它保证两图的包含关系，但没有硬性保证每张图沿高度只能出现一次转折：后面的纵向单调损失才负责抑制上下反复变化。四尺度前向坐标通道与嵌套概率

数出“边界上方有多少”，就能得到高度

对某一列，R 表示边界下方的概率，1−R 就表示边界上方的概率。若边界位于高度的四分之一处，边界以上约占整列的四分之一。因此，把所有高度的 1−R 相加并除以区域图高度，就得到归一化边界位置：

u(x)＝(1／h区域) Σi [1−R(i,x)]
ŷ(x)＝u(x) · (H输入−1)

例如 8 格的一列 R＝[0, 0, 0.5, 1, 1, 1, 1, 1]，边界上方占 2.5 格，u＝2.5／8＝0.3125。输入高 256 时，预测高度是 79.6875 像素。模型先在 64 列得到这种坐标，再沿宽度线性插值为 256 列；不需要先把区域图放大成 256×256，也不需要在每列寻找峰值。

因为 R下≤R上，其补集与均值关系相反，所以解码后自然满足 ŷ上≤ŷ下。这种顺序来自结构，而不是最后强行交换两条线。仅靠面积仍可能把不同形状的区域图解码成同一坐标，所以还需要下面的区域监督。

积分解码源码

标签也按“格子有多少在边界下方”构造

真实坐标先除以 255，得到归一化高度 u，再沿横向插值到区域图的 64 列。第 i 个纵向格子的中心是 (i＋0.5)／h，目标值为：

Q(i,x)＝clip([(i＋0.5)／h−u(x)] · h＋0.5, 0, 1)

完全在边界上方的格子取 0，下方取 1，边界穿过的格子取介于 0 和 1 的覆盖比例。这就是抗锯齿阶跃软标签。图中的 0.5 表示半格位于边界下方；它不是高斯峰，也不是人工额外画出的概率。对该标签的补集积分，会恢复原来的归一化高度。无效列通过掩码从损失中排除。

包里有什么，尚不能证明什么

本包提供区域法源码、配置、固定索引，以及一份命名为 train100 MobileNetV3-Large 蒸馏 best 的权重。固定索引记录 8,300 张原图、13,277 个含裁剪视图；train90 使用 7,470 张原图的 11,617 个视图训练、830 张原图按目录分组验证；train100 包含全部视图，仍在这 830 张上复评，存在训练重合。

新附的 300 张测试图均有两条目标标注，但移动清单中 52 张的原始路径也出现在附带 train100 索引里。这说明清单重合；尚未据此核实当前权重实际训练时是否见过它们。当前没有随包提供独立的 300 张对比结果，不能在此宣称区域法优于热图法，或把所有配置支持的实验组合视为均已完成。
