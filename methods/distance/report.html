距离场法：让每个位置报告离边界多远

103_距离场边界_参数07。任务仍是找真皮层下界与脂肪层下界；改变的是边界的表示、特征融合和监督方式。

热图法让一列响应在正确边界附近形成峰。距离场法让每个位置输出一个有正负号的竖直距离：边界上方为负，下方为正，边界处为零。于是已知当前位置，再减去预测距离，就能估计边界高度。

这里的“距离”有明确含义

源码目标是归一化行坐标减边界高度，不是像素到整条曲线最近点的二维欧氏距离。后续公式都依据这一实际定义。

本页沿用热图法中的卷积、骨干与训练基础，只展开本方法改变的计算。核心源码见 距离场前向与解码。

先重组特征，再预测两个距离场

输入是 256×256 灰度图，除以255后在网络内部复制为三个通道，按固定 ImageNet 均值和标准差归一化。新结构不再使用旧方案的可学习去噪首层和双尺度拼接。

MobileNetV3-Large 在四个阶段提取 24×64²、40×32²、112×16²、960×8² 特征。四组各用1×1卷积投影到48通道。最深8²投影后先经过一个48→48的可分离卷积块，再开始逐级放大，与本级浅层拼接成96通道，再加工回48通道；最终得到48×64×64。教师换成ResNet18，但同样提供四尺度特征。

融合块采用“逐通道3×3卷积 → 1×1通道混合 → 八组归一化 → SiLU”。相较普通卷积，先分别处理每通道邻域，再进行通道组合。最终加入两个绝对位置通道，形成50通道输入；预测头先加工为48通道，再用两个1×1卷积核输出两个场，经过tanh限制在−1到1。

1×256² → 四尺度骨干 → 48×64² → 加入纵横坐标 → 50×64² → 2×64² 距离场

位置通道明确告诉预测头当前高度与横向位置。纵向使用场网格像素中心，横向使用0～1端点采样；坐标网格与图像像素不能直接混用。

从一条浮点曲线构造整张距离场

标注解析仍然把同列点合并，再线性插值为256列；原始首尾点之间的插值列参与监督，区间外有填充值但无有效标签。本版本要求每条边界至少两个有效原始列。图像裁剪和缩放同步改变坐标与有效掩码。

损失把人工线横向重采样到场宽64，再把纵坐标除以255。对场的第r行，行中心为 g(r)=(r+0.5)/64。每个位置的目标就是两者的差：

d目标(r,x) = g(r) − y标注(x)/255

例如归一化边界在0.4，行中心0.1、0.3、0.5的目标分别为−0.3、−0.1、0.1。这里既有“在哪一侧”的信息，也有“竖直差多少”的信息。两条边界各生成一个目标场；有效掩码沿高度扩展，未标注列不参加场监督。

每一行都能提出一个边界估计

若场预测完全正确，g(r)−d(r,x)在同一列的每一行都等于真实边界高度。实际场有误差，代码更信任预测距离接近零的行，用它们的加权平均得到最终坐标：

α(r,x) = softmax高度(−|d(r,x)| / 0.03)
ŷ归一化(x) = clip[0,1] Σr α(r,x)[g(r)−d(r,x)]

0.03是近零权重的温度，越小越集中于场值接近零的位置；它不是高斯目标宽度，也不是沿像素分类的置信阈值。模型并不需要硬寻找唯一零交点，而是使用可微的权重与加权和。

两个头先各自解码，再按每列高度从小到大排列；距离场必须和坐标用同一索引同步交换。否则坐标损失说“这头是上界”，场损失却可能拿下界标签监督同一头。

排序后的64列坐标再线性插值到256列，乘255恢复输入像素单位。与旧热图法“先放大二维评分图再算坐标”不同，这里是在低分辨率场上先算坐标，再横向加密曲线。场还经sigmoid(d/0.025)变成“位于边界下方”的软区域，供蒸馏比较。

同时学准曲线位置与整个距离场

基础监督比较坐标、相邻列变化和层厚。坐标使用Smooth L1及两条线的相对权重1.076、0.923；走势项比较预测差分与标签差分，允许真实倾斜。距离场专用监督比较场值，并要求场沿归一化高度增加时，变化率接近1。

L监督 = L坐标 + 0.2L走势 + 0.3L厚度 + 0.5L距离场 + 0.1L竖直变化率

距离场误差内部采用beta=0.03的Smooth L1并乘16；近边界权重为1+3exp(−|目标距离|/0.08)，靠近零线处更重要。竖直变化率用相邻两行的场差乘场高64，与1比较。各项都有对应有效掩码；这些内部归一化和倍数也决定实际梯度，不能只看上式的系数大小。

学生还学习同方案、同划分的冻结ResNet18教师。教师与学生看同一增强图像，教师偏离人工标签越大，该点蒸馏相对权重越小：exp(−|教师坐标−标签|/8)×valid。蒸馏包括坐标Smooth L1和0.5倍软区域伯努利KL。

L训练 = L监督 + 0.488 × min(轮次/10, 1) × L蒸馏

门控在加权平均中归一化，表示位置之间的相对信任，不是保证整批损失按同一比例缩小。教师参数不更新，人工标签监督始终保留。

怎样训练、选模和使用

基础学习率0.000416059，AdamW权重衰减10−4，前5个调度索引预热，随后余弦下降；每微批次16张、累计3批更新一次，尾组按实际批次数平均；裁剪整体梯度范数到5。教师最多100轮、学生最多80轮，至少40轮后才允许连续20轮无选模改进触发早停。

选模使用两线相对固定参考MAE的最差比例，再加0.05倍平均比例，尽量避免只改善一条边界。最终重载best权重，学生PTH还需满足20,000,000字节限制。推理读取checkpoint中的架构，用单图灰度输入预测，再把曲线插值回原图横向坐标，纵坐标按原高/256恢复。
