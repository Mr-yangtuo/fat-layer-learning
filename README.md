# LayerLab · 脂肪层分割学习手册

中文静态学习网站：从原项目数据、模型、损失、训练、评估到端侧导出，建立理论与源码之间的对应。

- 14 节循序渐进的项目报告，包含基础概念、重要公式、9 幅可缩放矢量插图、逐列插值验算与概率加权坐标演示。
- 插值、融合预测、归一化、损失汇总与梯度方向均配有逐步数值推导；区分实际实现和设计理由。
- 19 个完整核心源码文件，2,572 行，114 个讲解片段。
- 每个文件先说明职责、输入输出、主要函数与类的分工、依赖关系和整体执行流程。
- 每段讲解包含作用原理、完整入参、重要变量与数据结构、执行步骤、API 调用与语法、返回值和实现注意事项。
- 复杂文件与函数配有专属 SVG 流程图，可滚动及放大；函数定义索引由源码 AST 提取。
- 全文搜索、文件下载、深链接、响应式布局、打印。
- 单文件 HTML，无 CDN、无网络依赖，本地双击即可阅读。

## 本地访问

直接打开 docs/index.html，或运行：

    python -m http.server 8765 --directory docs

访问 http://localhost:8765 。

## 重新生成

仅需 Python 标准库：

    python build.py

build.py 验证讲解行号、所有自定义函数与类的覆盖、文件导读与参数表结构、流程图连接、来源链接与片段顺序，将模板、样式、脚本、讲解和源码合并到 docs/index.html。

在原项目的 learning-site 目录下运行，会更新源码快照；独立克隆本仓库时使用已提交的 source/ 快照。修改原源码以后也必须更新对应讲解，重新审核语义，不应只更新快照。

## 内容布局

- report.html：可独立阅读的论文式项目汇报正文。
- figures/：9 幅报告矢量插图，构建时内嵌到单文件 HTML。
- content-{data,model,training}.json：文件导读、逐段讲解与专属流程图数据。
- source/：原项目核心源码快照，保持目录结构及行号。
- research-report.json：训练流程与实验记录分析。
- evidence.json：所展示实验数字的最小来源记录。
- app.js / style.css / template.html：路由、搜索、报告交互、排版和模板。
- reader.js / reader.css：源码研读、文件导读、详解面板、参数变量表和 SVG 流程图。
- docs/index.html：可独立打开、发布的最终网页。
- build-manifest.json：构建统计与源码 SHA256（UTF-8、换行规范化）。

只发布学习网站及核心代码，不包含原始数据集、图像、清单样本路径、模型权重、缓存或训练日志。

## 理论与实验证据的边界

本网站是基于源码及本地已有 JSON 结果制作的学习材料，没有重新训练模型。结构尺寸按默认 torchvision MobileNetV3 结构静态推导。train100 验证图与训练图重叠，不能作为泛化指标；train90 采用目录分组留出，不自动代表患者级隔离或独立最终测试。

原项目未被修改。已知问题在讲解中明确列出，包括增强错位、参数被覆盖、掩码遗漏、HD 距离忽略横坐标，以及导出缺少数值等价校验。

源码研读只提供阅读、查看、搜索和源码下载；没有手写输入、答题或掌握进度。全部内容和图示随 HTML 一起提供，可离线阅读。
